These are the retired ML103 Python notebooks and scripts on running large language models (LLMs) on high performance computing (HPC) clusters, covering local inference, fine-tuning and Slurm deployment. The workshop no longer teaches them, and nobody maintains them. Known issues include deprecated `transformers` APIs in the notebooks, and Slurm scripts that have not been tested on a current cluster. Treat them as reference material only, and check any code against current documentation before you run it. For the current workshop, see the [ML103 README](../../README.md).
